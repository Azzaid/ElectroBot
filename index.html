Unfair vote instructions (click to expand)
1. Install Nox android emulator (We're switched cause of blueStack screen size issues) From https://en.bignox.com/
2. Open Nox instance with 540X960 in perfomance settings tab and fix window size in display settings tab.
3. Open time princess "game"
4. Move mouse cursor somewhere into top left corner of game screen. Close to corner - faster it will detect player position. But cursor should be inside game screen.
5. Click "Shift+[". (Just like if you want to input "{") Could be inconvenient. Use both hands. After some time bot should highlight game screen. Check if it is highlighted as expected. Or nothing else will work.
6. Are you sure it was highlighted as expected?
If red square shifted - your mouse cursor was out of expected place. Move it and try hitting "Shift+1" again.
If red square too big or too small - you screen size is incorrect. Go back to pt 2.
7. Go to login screen
8. Fill in login/password pairs for all accounts you want to vote from
Use + button to add new input fields and - to remove.
